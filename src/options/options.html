Other notes and exports

A notes folder (Obsidian or plain Markdown) is read in the browser and never written to; its unchecked - [ ] items become tasks. An export file (Claude's conversations.json, or Gemini's MyActivity.json from Google Takeout) is read in the browser; only conversations from the last 30 days in which you name a date or a to-do are sent, at most 50, after you see how many.

Privacy
What Tuck may read on a page, and what it never reads.

    

      
 Page reading

      
      
Right before Tuck would nudge you about a page, it checks whether you are typing there (it notes when you last pressed a key, never which key), and reads up to 1,000 characters near where you type, from the conversation you last touched, or from the middle of the window, so a work chat on a social site does not count as drifting. Secrets are removed first. On Meta it goes to Muse Wonder 1.0, not Contributor, so it is not used for training. Only the verdict is kept, never the text. Pages with a password field and the sites below are never read.

GitHub repositories

      
Before Tuck names a PR or issue from your notes as a step, it checks on GitHub whether it is still open, and leaves it out if it was merged or closed. With one repository listed, "#12" means that one; with several, write "owner/name#12". Only public repositories, and only names, numbers, states and titles are read: no code, diffs or comments. Nothing is asked of GitHub while the list is empty.
